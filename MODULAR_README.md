# 🤖 AI-Консультант Бот - Архитектура с модулями

## 📋 Описание архитектуры

Бот построен как **модульная система**, где основной бот работает отдельно от опциональных платных фич:

### **БАЗОВЫЙ БОТ (включен по умолчанию)**
- ✅ 10 сообщений в день для каждого пользователя
- ✅ Защита от спама и prompt injection
- ✅ Сбор лидов в БД
- ✅ Быстрые ответы от GPT
- ❌ Без памяти диалогов
- ❌ Без дашборда

### **МОДУЛЬ ПАМЯТИ (платная фича +5K/месяц)**
- ✅ Сохранение полного диалога
- ✅ Резюме разговора (ИИ сжимает долгие диалоги)
- ✅ Классификация клиентов (целевой/теплый/левый)
- ✅ Динамические лимиты (целевые без ограничений)
- ✅ Контекст при ответах (бот помнит всё)

### **ДАШБОРД (платная фича, идет с памятью)**
- ✅ Веб-интерфейс синий + золото
- ✅ Таблица всех лидов
- ✅ Резюме разговора каждого клиента
- ✅ Фильтры по типам (целевой/теплый/левый)
- ✅ Статистика в реальном времени

## 🚀 Как запустить

### **БАЗОВЫЙ БОТ (без платных фич)**

```bash
# На сервере Beget
python telegram_bot.py
```

Все работает как обычно. Память и дашборд отключены.

### **С МОДУЛЕМ ПАМЯТИ + ДАШБОРД**

1. **Обнови config.py:**
```python
ENABLE_MEMORY = True      # Включить памяти
ENABLE_DASHBOARD = True   # Включить дашборд
```

2. **Установи Flask (если еще нет):**
```bash
pip install flask
```

3. **Запусти два процесса:**
```bash
# Терминал 1 - основной бот
python telegram_bot.py

# Терминал 2 - дашборд
python dashboard_app.py
```

**Дашборд откроется на:** `http://твой-сервер:8080`

## ⚙️ Как включить/отключить фичи

Все управляется в **config.py**:

```python
# config.py

# Включить модуль памяти? (сохраняет диалоги + резюме)
ENABLE_MEMORY = True        # или False

# Включить дашборд? (требует ENABLE_MEMORY = True)
ENABLE_DASHBOARD = True     # или False
```

### **Сценарии:**

**Для новых клиентов (базовый вариант):**
```python
ENABLE_MEMORY = False
ENABLE_DASHBOARD = False
```

**Для платящих (премиум):**
```python
ENABLE_MEMORY = True
ENABLE_DASHBOARD = True
```

## 💾 База данных

**Один файл `leads.db` для всего:**

### **Таблицы базового бота:**
- `leads` — клиенты и их первый вопрос
- `daily_limits` — счетчик сообщений в день
- `security_logs` — атаки и спам

### **Таблицы памяти (если ENABLE_MEMORY = True):**
- `chat_history` — весь диалог каждого клиента
- `user_summary` — резюме разговора (сжатое)
- `user_classification` — тип клиента

## 🔄 Развертывание на Beget

### **Базовый вариант (без памяти):**

```bash
cd ~/ai-consultant-bot

# Установь зависимости
pip install -r requirements.txt --break-system-packages

# Запусти (через supervisor или nohup)
nohup python telegram_bot.py > bot.log 2>&1 &
```

### **С памятью + дашборд:**

```bash
# Два процесса (через supervisor)

# /etc/supervisor/conf.d/bot.conf
[program:telegram_bot]
command=python /home/fromruss/ai-consultant-bot/telegram_bot.py
directory=/home/fromruss/ai-consultant-bot

[program:dashboard]
command=python /home/fromruss/ai-consultant-bot/dashboard_app.py
directory=/home/fromruss/ai-consultant-bot
```

```bash
supervisorctl reread
supervisorctl update
supervisorctl start all
```

## 📊 Как работает классификация

Бот автоматически определяет тип клиента:

**Целевой** — написал разработчику (лучший вариант)
**Теплый** — прошел по воронке но не написал
**Левый** — пишет только про погоду/фигню
**Неизвестный** — новый пользователь

Лимиты:
- Целевой: 999 сообщений (без ограничений)
- Теплый: 20 сообщений
- Левый: 3 сообщения
- Неизвестный: 10 сообщений

## 🎯 Сценарий для продажи

1. **Клиент пишет** → базовый бот отвечает
2. **Клиент обращается** → ты видишь его в дашборде (нужна память!)
3. **Клиент платит** → включаешь `ENABLE_MEMORY = True`
4. **Теперь бот помнит** → лучше общается, давит на боли
5. **Целевые выявляются** → можешь их вычислить в дашборде
